# Mini ATS – Applicant Tracking System

## Purpose
This project is a frontend web application that functions as an Applicant Tracking System (ATS).

It allows companies to manage job postings and candidates in a structured and secure way.

---

## Target Group
- Small and medium-sized companies
- HR personnel
- Recruitment consultants

---

## Application Type
- Single Page Application (SPA)
- Built with Next.js
- Accessible via desktop and mobile

---

## Requirements

### Authentication & Security
- Secure user authentication
- Role-based access control (admin / customer)
- Row Level Security (RLS) in the database

### Job Management
- Create job postings
- Manage job postings

### Candidate Management
- Create candidates
- Connect candidates to specific jobs

### Kanban Board
- Display recruitment stages
- Move candidates between stages

### Technical Quality
- Follow accessibility guidelines
- Ensure performance optimization
- Use structured architecture

---

## Technologies
- Next.js
- TypeScript
- Tailwind CSS
- Supabase (Auth + Database)
- Git & GitHub

---

## Scope

### Included
- Authentication system
- Role-based access
- Job and candidate management
- Secure database configuration

### Excluded
- AI-based candidate matching
- External email integration
- Advanced reporting
