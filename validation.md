# Validation Instructions

Your task is to compare the current project implementation with the requirements defined in:

docs/project-description.md

## Output format:

1. List all required features
2. Mark each as:
   - ✅ Implemented
   - ⚠️ Partially implemented
   - ❌ Missing

3. Explain:
   - What is missing
   - What is incorrect
   - What can be improved

4. Check:
   - Authentication
   - Role-based access (admin / customer)
   - Job management
   - Candidate management
   - Kanban board functionality
   - Database security (RLS)
   - Performance and structure

5. Give a final summary:
   - Is the project aligned with the description?
   - What must be fixed before submission?
